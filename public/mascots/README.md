# Mascot GLB Files

Place your additional mascot GLB files in this folder:

- `mascot2.glb` - Second mascot (will use male voice)
- `mascot3.glb` - Third mascot (will use male voice)

The first mascot uses the existing `avatar.glb` file in the public folder and will use a female voice.

## Voice Assignment:
1. **avatar.glb** (Mascot 1) - Female voice: "Welcome to the Gates of Display"
2. **mascot2.glb** (Mascot 2) - Male voice: "from Kardivers"  
3. **mascot3.glb** (Mascot 3) - Male voice: "Experience the future"

The mascots will speak in sequence with a slight delay between each voice, creating a natural conversation effect.
